# Execution evidence

This directory was generated by `python scripts/prove.py`.

- `tests.txt`: actual unittest output.
- `demo.json`: actual demonstration output.
- `sha256.json`: source file fingerprints.
- `report.json`: runtime, commands and exit codes.
